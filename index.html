ManySpeech-CLI

轻量化本地命令行语音识别工具｜全程离线｜无需云端

✨ 核心功能

🎙️ 语音识别（ASR）

支持 online / offline / 2pass 三种模式，麦克风实时识别 + 本地音频转写。

🎯 语音端点检测（VAD）

自动剔除静音、噪音，精准切割语音片段，支持双 VAD 模型切换。

📝 标点符号恢复

无标点文本自动补全标点，支持文件批量处理与直接输入。

📄 多格式输出

支持 纯文本、JSON、SRT 字幕、VTT 字幕，一键生成视频字幕。

⚡ 离线本地推理

全程本地运行，不上传云端，保护隐私，断网可用。

🛠️ 智能模型管理

自动检测、自动下载所需模型，无需手动配置。

🚀 快速开始

安装完成后，直接在终端输入：

manyspeech asr -t online -i mic

麦克风实时语音识别（按 ESC 退出）


本地音频文件识别：

manyspeech asr -t offline -f test.wav --format srt
查看完整文档

📌 支持的命令

  • manyspeech asr - 语音识别
  • manyspeech vad - 语音端点检测
  • manyspeech punc - 标点恢复
  • manyspeech --debug - 调试模式
  • manyspeech --show-config - 查看配置
