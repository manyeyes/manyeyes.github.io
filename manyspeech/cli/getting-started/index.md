# 快速开始

欢迎使用 ManySpeech-CLI！本指南将帮助你快速上手。

## 两种分发方案

| 版本类型       | 使用特点           | 适用场景      |
| ---------- | -------------- | --------- |
| **免安装绿色版** | 解压即可运行，无注册表残留  | 临时使用、便携部署 |
| **一键安装包**  | 向导式安装，自动配置环境变量 | 长期日常使用    |

> 💡 **推荐**：使用一键安装包，安装完成后可在终端直接输入 `manyspeech` 调用。

## 两种使用模式

| 模式        | 启动方式                      | 适用场景      |
| --------- | ------------------------- | --------- |
| **交互模式**  | 直接双击 exe 或运行 `manyspeech` | 手动测试、探索功能 |
| **命令行模式** | `manyspeech <子命令> [参数]`   | 脚本调用、自动化  |
