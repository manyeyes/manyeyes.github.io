# X-ASR-zh-en：軽量高精度中英バイリンガル・オフライン＆ストリーミング音声認識モデル

## 一、プロジェクト背景と開発チーム

### 1.1 業界の開発背景

ローカルでのオフライン音声対話、プライバシーを重視したリアルタイム文字起こし、中英バイリンガル混在音声認識といった主流のニーズに対して、既存のオープンソースASRモデルには多くの課題があります。パラメータ数の多いモデルはデプロイコストが高く軽量化が難しく、軽量モデルはバイリンガル精度の不足、ストリーミングとオフライン推論の非互換、汎化性能の弱さなどの問題を抱えています。これらの核心的な課題を解決するため、複数の大学の研究チームが連携して**X-ASR-zh-en 中英バイリンガル・オフライン＆ストリーミング統一ASRモデル**を開発しました。超軽量ボリューム、高精度、低遅延、両モード統一対応を特徴とし、学術研究と産業向け軽量実装の両方のニーズを満たし、開発者に低コストで低障壁なバイリンガル音声認識ソリューションを提供します。

### 1.2 開発チームとオープンソース宣言

**開発機関**：上海交通大学、上海創智学院が主導し、复旦大学、華中科技大学など複数の大学の研究力と連携して開発された産学連携による軽量音声認識のオープンソース成果です。

**オープンソースライセンス**：本モデルは **Apache 2.0 ライセンス** の下で正式に公開され、重み、ソースコード、デプロイリソースが完全にオープンです。**個人学習、学術研究、無償での商用利用** が可能で、追加の許諾は不要です。

## 二、モデルの概要

X-ASR-zh-en は、Icefall、K2 フレームワークと Zipformer Transducer アーキテクチャを基に構築された軽量中英バイリンガル統一音声認識モデルです。**100万時間** のオープンおよび収集によるバイリンガル音声データで訓練され、パラメータ数はわずか **0.16B** という超小規模です。最大の特徴は **単一モデルでストリーミング（リアルタイム）認識とオフライン高精度認識の両モードを統一推論** できることで、重みやコードロジックの切り替えは不要です。

モデルは多粒度の低遅延推論にネイティブ対応しており、160ms / 480ms / 960ms / 1920ms の4つの標準チャンクモードを提供します。また、中英混在認識、自動句読点付与、英文の大文字・小文字正規化をネイティブサポートしています。ONNX 量子化最適化により、CPU のみで低遅延推論が可能で、GPU やクラウドへのデータ送信は不要です。極限の軽量デプロイと高精度認識を両立しており、総合性能は同クラスの軽量オープンソースASRモデルを大きく上回ります。

## 三、コアアーキテクチャと主要機能

### 3.1 アーキテクチャの強み

業界で先進的な Zipformer Transducer 効率的時系列モデリングアーキテクチャを採用しています。従来の CNN や RNN と比較して、長い時系列のコンテキストモデリング能力に優れ、長文音声や複雑環境下での認識誤差を効果的に低減できます。Icefall、K2 フレームワークによる精緻な訓練スケジューリングにより、収束安定性と中英バイリンガルの汎化能力が大幅に向上しており、極小パラメータで高精度な両モード推論を実現する基盤アーキテクチャとなっています。

### 3.2 主な機能

- **両モード統一推論**：単一モデル・単一の重みで、リアルタイムストリーミング復号とオフライン一括復号の両方をネイティブサポート。あらゆる音声認識業務シナリオに対応。
- **多粒度低遅延対応**：160ms、480ms、960ms、1920ms の4段階の推論チャンクを内蔵。超低遅延のライブ配信、標準的な会議文字起こし、長音声の一括認識など、異なる遅延要件のシナリオに柔軟に適応。
- **ネイティブ中英バイリンガル能力**：統一バイリンガルモデリングにより、中英混在音声を高精度に認識。出力には自動で正しい句読点と英文の大文字・小文字が付与される。
- **ゼロ・コンピューティング依存デプロイ**：0.16B の超軽量パラメータにより、CPU のみでの推論が可能。ONNX 量子化最適化により、エッジ端末からサーバーまで迅速な軽量デプロイが実現。
- **標準化されたオープンソースデプロイ**：[Sherpa-ONNX](https://github.com/k2-fsa/sherpa-onnx) 公式デプロイエコシステムにネイティブ対応。完全な ONNX 推論ファイル、サーバースクリプト、テストツールが付属し、すぐに使えて拡張性も高い。

## 五、推論デプロイ

X-ASR-zh-en 公式推奨のランタイムは [**Sherpa-ONNX**](https://github.com/k2-fsa/sherpa-onnx) です。本モデルはこのオープンソースデプロイエコシステムにネイティブ対応しており、完全な ONNX 推論ファイル、サーバースクリプト、テストツールが付属しています。プロフェッショナル開発者向けのプロジェクト統合、バッチ推論、WebSocket ストリーミングサービスなどのエンジニアリングシナリオに対応します。ユーザーのニーズに合わせて、公式標準デプロイ方法と軽量クイック体験方法の両方を提供します。

### 5.1 公式標準デプロイ：Sherpa-ONNX によるエンジニアリングデプロイ

プロジェクトリポジトリには完全な Sherpa-ONNX デプロイリソースが含まれており、異なるチャンクサイズの ONNX エンコーダ・デコーダ・ジョイナーの重みファイル、および付属の推論スクリプトが用意されています。CPU のみでの軽量ストリーミングサービスのデプロイが可能で、リアルタイム音声認識サービスを迅速に構築でき、プロジェクトの二次開発や実サービスへの実装に適しています。

#### 環境デプロイ手順

プロジェクトリソースをダウンロード後、deployment ディレクトリに移動し、仮想環境を作成して依存パッケージをインストールします。

```bash
cd deployment
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

#### ストリーミング推論サービスの起動

160ms 低遅延モデルを例として、CPU ストリーミング認識サービスを起動します。ポート、スレッド数、復号パラメータはカスタマイズ可能です。

```bash
python infer_and_client/sherpa_streaming_server.py \
  --host 0.0.0.0 \
  --port 8766 \
  --tokens models/chunk-160ms-model/tokens.txt \
  --encoder models/chunk-160ms-model/encoder-160ms.onnx \
  --decoder models/chunk-160ms-model/decoder-160ms.onnx \
  --joiner models/chunk-160ms-model/joiner-160ms.onnx \
  --provider cpu \
  --sample-rate 16000 \
  --feature-dim 80 \
  --num-threads 1 \
  --decoding-method greedy_search \
  --model-type zipformer2 \
  --enable-endpoint-detection 0 \
  --text-format none
```

#### 音声ファイルを用いたテスト推論

サービス起動後、クライアントスクリプトを使ってローカルの WAV 音声を読み込み、リアルタイムストリーミング推論をシミュレーションしてテストできます。

```bash
python infer_and_client/sherpa_streaming_client.py \
  --server-uri ws://127.0.0.1:8766 \
  --wav /path/to/test.wav \
  --chunk-ms 100 \
  --simulate-realtime 1
```

### 5.2 極簡推論：ManySpeech-CLI コマンドライン（クイック体験）

**[ManySpeech](https://github.com/manyeyes/ManySpeech)** はオープンソースの音声 AI モデル推論プロジェクトであり、汎用 ONNX 音声モデル推論 SDK として利用できます。開発者は二次開発や機能拡張が可能で、様々な軽量音声認識モデルの実装に適しています。**ManySpeech-CLI** は ManySpeech カーネルをベースにした軽量コマンドラインツールで、複雑な開発設定を取り除き、ゼロコンフィグで即座に使えることを目指しています。一般ユーザーがモデルの効果を簡単に試したり、開発者が日常的な機能検証を行うのに最適です。

本ツールは X-ASR-zh-en の全モデルと完全互換性があり、マイクからのリアルタイム音声取り込み、ストリーミングリアルタイム復号、中英混在認識、自動句読点付与、大文字・小文字正規化をサポートします。重みの手動読み込みや複雑なエンジニアリングデプロイは不要で、モデル性能を素早く検証するための最適な軽量ソリューションです。

#### ターミナルでのリアルタイムマイク推論の使用方法

[ManySpeech-CLI のインストール](https://manyeyes.github.io/manyspeech/cli/getting-started/installation.html) 後、以下のコマンドを実行するだけで、低遅延リアルタイム中英バイリンガル音声認識が開始されます。

```bash
manyspeech asr -t online -md k2transducer-zipformer-x-asr-zh-en-480ms-onnx-online-20260601 -m chunk -i mic
```

#### 主要コマンドパラメータの説明

- **-t online**：リアルタイムストリーミング推論モードを指定。マイクからのリアルタイム音声入力に適応し、低遅延出力を保証します。
- **-md k2transducer-zipformer-x-asr-zh-en-480ms-onnx-online-20260601**：480ms 均衡版モデルをロード。認識精度と推論遅延のバランスが良く、ほとんどの日常・オフィスシナリオに適しています。
- **-m chunk**：チャンクストリーミング推論機構を有効化。モデル本来の復号アーキテクチャに適合し、安定した認識を実現します。
- **-i mic**：音声入力ソースとしてマイクを指定。リアルタイムで音声を収音し、即座に文字起こしします。

コマンド実行後、ターミナルは継続的にマイク入力を監視し、中英混在音声認識、句読点補完、英文大文字・小文字正規化を自動で行います。一般ユーザーはモデル能力を簡単に体験でき、開発者は ManySpeech オープンソースカーネルをベースに二次開発し、モデル推論能力を自身のプロジェクトに迅速に統合できます。
