# ManySpeech

軽量ローカル<br/>音声処理ツールキット

> ネイティブでオフライン認識・リアルタイムストリーミング認識、クラウド不要、ゼロコンフィグ起動

[クイックスタート](/ja/getting-started/) | [GitHub](https://github.com/manyeyes/ManySpeech)

## Features

- **🎯 デュアルコア駆動**: オフライン音声認識 + マイクリアルタイムストリーミング認識、全シーンをカバー
- **🤖 スマートモデル管理**: 必要なONNXモデルを自動検出・ダウンロード、完全オフラインでローカル推論
- **📝 複数フォーマット出力**: SRT字幕、JSON、プレーンテキストなどに対応
- **⚡ ONNXハイパフォーマンス推論**: マルチスレッド推論に対応、CPUコア数を自動検出しインテリジェントに適応
- **🔧 デュアルモード使用**: インタラクティブモード + コマンドラインモード、さまざまなシーンに柔軟に対応
- **📦 ゼロコンフィグで即利用**: 解凍してすぐ使える、複雑な環境設定は不要
