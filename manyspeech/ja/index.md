# ManySpeech

軽量型ローカル音声 AI

> ネイティブでオフライン＆リアルタイムのストリーミング認識をサポート、クラウド不要・追加設定不要

[クイックスタート](/cli/getting-started/) | [GitHub](https://github.com/manyeyes/ManySpeech)

## Features

- **🎯 デュアルコア駆動**: オフライン音声認識 + マイクのリアルタイムストリーミング認識で全シーンをカバー
- **🤖 スマートモデル管理**: 必要なモデルを自動検出・ダウンロード、完全オフラインでローカル推論
- **📝 複数フォーマット出力**: SRT字幕、JSON、プレーンテキスト等をサポート
- **⚡ 高パフォーマンス**: マルチスレッド推論、CPUコア数の自動検出で最適化
- **🔧 二つの利用モード**: インタラクティブモード + CLIモードで柔軟に運用可能
- **📦 ゼロコンフィグで即利用**: 解凍してすぐ使える、複雑な環境構築は不要
