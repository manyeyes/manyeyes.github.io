# ManySpeech

轻量化本地语音识别工具

> 原生支持离线识别、实时流式识别，无需云端、无需额外配置

[快速开始](/cli/getting-started/) | [GitHub](https://github.com/manyeyes/ManySpeech)

## Features

- **🎯 双核驱动**: 离线音频识别 + 麦克风实时流式识别，覆盖全场景
- **🤖 智能模型管理**: 自动检测并下载所需模型，全程离线本地推理
- **📝 多格式输出**: 支持 SRT字幕、JSON、纯文本等多种输出格式
- **⚡ 高性能**: 支持多线程推理，自动检测CPU核心数智能适配
- **🔧 双模式使用**: 交互模式 + 命令行模式，灵活适配不同场景
- **📦 零配置开箱**: 解压即用，无需复杂的环境配置
