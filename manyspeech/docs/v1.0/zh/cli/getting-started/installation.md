# 安装指南

## 系统要求

- Windows 10 / 11 (64位)
- 建议 4GB 以上内存
- 麦克风（如需实时识别）

## 方式一：一键安装包（推荐）

1. 下载最新版本的安装包 `.exe` 文件
2. 双击运行安装程序
3. 按照向导提示完成安装
4. 安装完成后，打开 cmd 或 PowerShell 即可使用

```bash
manyspeech --help
```

## 方式二：免安装绿色版

1. 下载绿色版压缩包
2. 解压到任意目录（如 `D:\Tools\ManySpeech`）
3. 进入目录，双击 `manyspeech-cli.exe` 运行

> 💡 **提示**：如需全局调用，可将程序所在目录添加到系统 PATH 环境变量。

## 验证安装

```bash
manyspeech --help
```

如果显示帮助信息，说明安装成功。
