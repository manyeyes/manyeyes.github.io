# ManySpeech

Lightweight Local Speech Toolkit

> Native offline recognition, real-time streaming, no cloud required, no extra configuration.

[Get Started](/en/cli/getting-started/) | [GitHub](https://github.com/manyeyes/ManySpeech)

## Features

- **🎯 Dual-Core Engine**: Offline audio recognition + Real-time microphone streaming.
- **🤖 Smart Model Management**: Auto-detect and download models. Fully offline local inference.
- **📝 Multi-Format Output**: Supports SRT subtitles, JSON, plain text, and more.
- **⚡ High Performance**: Multi-threaded inference with automatic CPU core detection.
- **🔧 Dual Mode Usage**: Interactive mode + CLI mode, flexible for different scenarios.
- **📦 Zero Config**: Ready to use out of the box, no complex environment setup.
